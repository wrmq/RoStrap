# RoStrap

A Roblox launcher for Windows. **RoStrap Serene** starts Roblox with your FastFlags, mods and settings, shows your friends and private servers, and keeps Roblox and itself up to date.

**[Download RoStrapSerene.exe](https://github.com/wrmq/RoStrap/releases/latest/download/RoStrapSerene.exe)**

Windows 10 or 11, 64 bit. Nothing to install: download it and run it.

## New in 2.8

| | |
|---|---|
| **Friends** | See who's online and what they're playing, then join them in one click |
| **Private servers** | Yours and the ones you're invited to, with a search for names, games and owners |
| **Join from a link** | Paste a server, private server or profile link and jump straight in |
| **Discord status** | Show your game on Discord with a Join button for friends. Off until you switch it on in Settings |
| **What's new** | After an update, RoStrap shows what changed |

## What it does

| | |
|---|---|
| **Home** | Your last and favourite games, Play, and Open Roblox |
| **Friends** | Round avatars like on Roblox, with who's playing what, and your private servers under them |
| **FastFlags** | An editor with ready-made sets, plus profiles you can switch between, import and export |
| **Mods** | Your own font, mouse cursors, painted sky presets or your own sky, and your own replacement files |
| **Auto rejoin** | Gets you back into the game after a disconnect (off by default) |
| **Roblox updates** | New Roblox versions download in the background while Roblox isn't open |

## Your Roblox login

The Friends page uses the login of the Roblox app on your PC, so there's nothing to sign into in RoStrap. It reads it only for that page, keeps it in memory, never saves it anywhere and only ever sends it to roblox.com. If the Roblox app isn't logged in, the page asks you to log in there first.

## Privacy

RoStrap has no account, no ads and no tracking. It only talks to:

| | |
|---|---|
| **Roblox** | Game names and pictures, your friends and private servers, and Roblox updates |
| **GitHub** | Checking these releases for a newer RoStrap |
| **Discord** | Only the Discord app on your own PC, and only if you switch the Discord status on |

Settings stay on your PC, in `%LOCALAPPDATA%\RoStrap`.

## Safety

The first time you run it, Windows may say "Windows protected your PC", because the exe isn't code-signed. Click **More info**, then **Run anyway**.

## Updates

RoStrap Serene updates itself from these releases. It checks when it opens and every 3 hours, downloads a newer version in the background, checks it against GitHub's checksum and installs it when you close it.
